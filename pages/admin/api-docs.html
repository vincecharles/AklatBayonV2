API Reference

AklatBayon API

The AklatBayon API provides programmatic access to the FEATI Library Management System. All endpoints follow RESTful conventions and return JSON responses.

Base URL

https://aklatbayonfeati.netlify.app/api/v1

lock Authentication

All API requests require authentication via Bearer token.

# Include the token in your request headers
curl -H "Authorization: Bearer YOUR_API_TOKEN" \
https://aklatbayonfeati.netlify.app/api/v1/books

menu_book Books

GET /api/v1/books List all books

Returns a paginated list of all books in the repository.

Response

{
  "data": [
    {
      "id": "b001",
      "title": "Introduction to Algorithms",
      "isbn": "978-0-262-03384-8",
      "year": 2022,
      "copies": 5,
      "available": 3
    }
  ],
  "total": 142
}
POST /api/v1/books Create a book

Creates a new book entry in the library catalog.

Request Body

{
  "title": "Data Structures",
  "isbn": "978-0-13-468599-1",
  "author_id": "a001",
  "category_id": "c002",
  "copies": 3
}
DELETE /api/v1/books/:id Delete a book

Permanently removes a book from the catalog. Requires admin privileges.

GET /api/v1/transactions List transactions

Returns all borrow/return transactions with filtering options.

Query Parameters

statusFilter by status (borrowed, returned)
student_idFilter by student
POST /api/v1/transactions Create transaction

Creates a new borrow transaction.
