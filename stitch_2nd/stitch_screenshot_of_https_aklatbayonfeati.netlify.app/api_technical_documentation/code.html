List all books

GET /v2/books

Retrieve a paginated list of books from the AklatBayon catalog. This endpoint supports extensive filtering by genre, availability, and publication date.

Query Parameters

Parameter Type Description
limit integer The number of items to return. Default is 20. Max 100.
genre string Filter books by genre name (e.g. "Fiction", "History").
available boolean If true, only returns books currently in stock.

Response Attributes

data Array of Objects

The collection of book records retrieved.

meta Object

Pagination metadata including total_count and next_cursor.
